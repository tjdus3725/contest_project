# 5분 시연

시연은 `demoDebug`로 진행합니다. 긴급 번호는 모의 실행되어 실제 전화가 걸리지 않습니다.

1. **가족** → 동승자 추가 → 별칭 `아이`, 연령 `유아`, 필수 시설 `기저귀 교환대` 저장.
2. **홈** → 동승자와 조건 표시 확인 → 이동 시작.
3. **장소 찾기** → 가상 장소 시연 상태 확인. A/B는 후보, 교환대 미확인 C는 제외됨.
4. `식사` 조건 선택 → A만 표시. `수유 공간`까지 선택하면 결과 없음. 앱이 필수 조건을 임의로 해제하지 않음을 확인.
5. 추가 조건 해제 → A 선택 → 홈에서 `실제 내비게이션 미전송` 상태 확인.
6. **SOS** → 텍스트 `아이 의식이 없어요 화장실 찾아줘` → 휴게소 검색보다 119 우선 안내가 나오는지 확인.
7. `119 구조·구급` → 실제 통화가 없는 시연 메시지 확인.
8. **MY** → 주행 제한 시연 → 가족 편집/상세 입력이 잠기지만 SOS 탭은 접근 가능.
9. 주행 제한 시연 해제 → 저장 정보 삭제 → 가족 목록 초기화 확인.

음성 시연은 MY에서 처리 동의 후 기기에 한국어 인식 서비스가 있을 때 가능합니다. 없으면 텍스트와 상황 버튼으로 동일한 로직을 시연합니다.

## 실제 Pleos 시험 (별도)

- 에뮬레이터에 앱 설치 → 정차 상태 확인 → 실제 목적지를 차량 내비게이션에 먼저 설정.
- 출처·확인일을 갖춘 실제 장소를 직접 등록. 가상 모드 해제.
- 장소 선택 → 첫 경유지 변경 확인 → SDK 요청/오류/응답 상태 확인.
- 실제 경유지가 반영되었는지 차량 내비게이션에서 확인.
- 내비게이션 서비스 중단, 권한 거절, 기존 경유지 존재, 목적지 없음, 연결 해제, 주행 중 상태를 각각 검증.
- 실제 SOS 번호는 시험 목적으로 호출하지 않음. 전화 앱 연결 검증은 테스트용 연락처로 수행.
