# 기능·데이터 계약

## 실제 지도 확장

현재 버전은 `LivePlacesPanel` + `RoutePlanner` + `MapApi` + `server/`로 실제 카카오 지도·장소·자동차 경로를 지원합니다. 가상 목록은 UI에서 제거했고 테스트 fixture만 유지합니다. 키 설정과 최신 데이터 범위는 [카카오 설정](KAKAO_SETUP.md)을 따릅니다. `FamilyMember.kind`는 사람·반려견·반려묘·기타 반려동물을 구분합니다. `PET_ALLOWED`는 확인된 시설에만 적용하며 키워드 검색 결과만으로 동반 허용을 확정하지 않습니다.

실제 검색 후보의 마커는 시설 추천 확정과 구분합니다. 최대 8개 검색 지점에서 가져온 부분 결과를 경로 선분과 약 3km 이내인지 필터하고, 선택 후보를 경유하는 자동차 경로를 별도 조회합니다. 경로 미리보기와 Pleos 내비게이션은 다른 경로를 사용할 수 있습니다. 가족 의료 정보는 지도 서버에 전달하지 않습니다.

## 탭과 상태

1. **홈**: 가족 설정과 추가 검색 조건을 합쳐 표시. 이동 시작 시 휴식 시각 기록, 완료 기록 시 타이머 재설정. 도착/주차는 자동 추론하지 않음.
2. **장소 찾기**: 필수 시설 모두 `CONFIRMED`인 장소만 후보. 미확인 시설은 `UNKNOWN`; `ABSENT`와 분리. 선택 조건이 없으면 등록 장소 표시. 현재는 시설 적합성 순위이며 거리·우회시간·진행방향 순위가 아님.
3. **SOS**: 연락 버튼 → 음성/텍스트 또는 상황 버튼 → 위험 규칙 → 분류/보류 → 사전 작성 단계별 안내. 상황 대화와 위치는 메모리에만 유지.
4. **가족**: 동승자별 프로필, 이번 이동 참여 여부, 시설 조건, 선택적 의료 참고 사항·연락처. 비동승자는 추천 조건에서 제외.
5. **MY**: 보험사·차량·음성 동의·휴식 간격·준비물 저장. 전체 삭제 시 Keystore 키와 암호화 파일 모두 제거.

## 핵심 데이터

- `FamilyMember`: id, name, age, onboard, needs, medical, contact.
- `Place`: id, name, latitude, longitude, facilities, direction, source, checkedAt, hours, demo, note.
- `Assessment`: situation, urgent, headline, steps, optional facility.

실제 장소를 등록하려면 이름, 유효한 좌표, 정보 출처, 미래가 아닌 ISO 날짜가 필요합니다. 선택하지 않은 시설·접근 방향·운영시간은 미확인으로 유지합니다. 오류 제보는 해당 장소의 모든 시설을 미확인으로 변경하므로 필수 시설 추천에서 빠집니다. 제보를 외부 기관에 전송하지 않습니다.

## 내비게이션 계약

`NavigationGateway`는 demo와 pleos 소스셋으로 분리합니다. demo는 외부 호출 없음. pleos는 연결 상태 확인 후 `addWaypoint`를 요청합니다. 가상 장소 차단, 중복 요청 제한, 오류 콜백, 15초 응답 한계, Activity와 독립적인 ViewModel 정리를 적용합니다.

NaviHelper의 일반 경유지 목록 이벤트만으로 특정 요청 성공을 확정하지 않습니다. 실제 반영은 내비게이션에서 확인해야 합니다. 차후 요청별 상관관계와 좌표·목적지 대조를 검증한 뒤 성공 상태를 추가해야 합니다.

## 안전성과 개인정보

- AI 결과는 의료 위험 확률이나 진단이 아님. 위험 신호는 추가 질문보다 우선.
- 낮은 유사도/근접한 후보 점수는 `UNKNOWN`으로 보류.
- 정확한 처치·약물·수리 조작을 생성하지 않음.
- SOS는 인증·가족 등록·모델 응답을 기다리지 않음.
- 음성인식 서비스 별도 동의, 마이크/위치 런타임 권한 및 거절 대체 흐름.
- Android Keystore AES-GCM, AtomicFile 저장, 앱 백업 비활성화.
- 암호화 파일을 읽지 못하면 보존하고 저장을 차단. 사용자가 명시적으로 초기화 가능.
- AAOS UX restrictions 사용. 주행 상태 미확인 시 편집 잠금. 심사 승인 없는 주행 중 사용을 주장하지 않음.

## 후속 작업

- 실제 지원 상태 확인 후 Pleos STT/TTS/FusedLocation 어댑터.
